練習用の書き捨てのプログラム（cpp_practice、python_practice など）を書くときは、python-coding スキルなどのコーディング規約（長い名前、型ヒント、docstring など）を当てはめず、簡単に書く。

**Why:** 2026-11-03 に、getattr の例を python-coding スキルの決まりに沿って書いたところ、ユーザーが「ここでは書き捨てのプログラムを書いていますから、なんのスキルも使わずに書いて大丈夫」と言った。

**How to apply:** 練習用のリポジトリで例やコードを書くときは、スキルを呼ばず、ユーザーのコードの書き方に合わせて短く書く。ROBO_NEXT など本番のコードでは、これまでどおり規約に従う。
