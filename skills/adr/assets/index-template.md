# ADR 管理台帳

このファイルは、ADR の**状態**、**ADR 同士の関係**、**更新の記録**を管理する唯一の場所です。
個々の ADR ファイルには、状態も関係も書きません。どの ADR がいま有効かは、必ずこのファイルで判断します。

|---|---|---|---|
| [ADR-0001](ADR-0001-short-name.md) | 決定の内容 | 採用 | YYYY-MM-DD |

## 更新の記録

ADR を足したとき、追記したとき、置き換えたとき、削除したときに、1行ずつ足します。新しいものを下に書きます。

| 日付 | ID | 種類 | 内容 |
|---|---|---|---|
| YYYY-MM-DD | ADR-0001 | 新規 | 決定の内容を、短く書く |

種類は、次の5つから選びます。

| 種類 | 意味 |
|---|---|
| 新規 | 新しい ADR を書いた |
| 追記 | 既存の ADR の内容を、書き足した、または書き換えた。決定そのものは変わっていない。ADR の中に、書き足した印は残さない |
| 訂正 | 既存の ADR の、内容の誤りを直した。決定そのものは変わっていない。ADR の中に、直した印は残さない |
| 置き換え | 新しい ADR が、古い ADR を置き換えた。ID の欄には、新しい ADR の ID を書く |
| 削除 | ADR を削除した |

## 状態の種類

| 状態 | 意味 |
|---|---|
| 提案 | 検討中で、まだ決定していない |
| 採用 | 現在有効な決定 |
| 置き換え済み | 新しい ADR に置き換えられた。現在は無効 |
| 廃止 | 置き換える ADR なしで無効になった |

## 関係の種類

| 関係 | 意味 |
|---|---|
| 置き換える | 元の ADR が、先の ADR を無効にして取って代わる。先の ADR の状態は「置き換え済み」にする |
| 前提にする | 元の ADR は、先の ADR の決定が有効であることを前提にしている |
| 関連する | 上の2つには当たらないが、あわせて読む必要がある |
