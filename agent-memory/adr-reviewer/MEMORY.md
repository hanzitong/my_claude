# adr-reviewer のメモリー

Claude Code が、このエージェントを起動するたびに、このファイルの最初の200行を読み込む。短く保つ。

## 書くこと

- このプロジェクトで繰り返し見つかること
- ユーザーが示した好み
- ユーザーが認めた例外

書くときは、日付をつける。

## 書かないこと

- 文書（ADR、INDEX.md、仕様書、設計書、スキル、ルール）に書いてあること
- 認証情報

文書に書いてあることは、メモリーに写さず、その文書を読む。
