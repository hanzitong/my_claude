## 書くこと

- このシステムの前提として確かめられたこと（例: 非常停止をどこが受け持つか）
- ユーザーが承知のうえで、そのままにすると決めた懸念と、そう決めた理由

書くときは、日付をつける。

## 書かないこと

- 文書（ADR、INDEX.md、仕様書、設計書、スキル、ルール）に書いてあること
- 認証情報

文書に書いてあることは、メモリーに写さず、その文書を読む。
