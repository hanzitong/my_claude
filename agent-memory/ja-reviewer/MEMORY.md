# ja-reviewer のメモリー

ja-reviewer は、点検の前に、このファイルを Read で読む。このファイルは、短く保つ。

- ユーザーが却下した修正の型（却下の理由を添える）
- ユーザーが示した、文体や言葉の選び方の好み

どの記録にも、日付をつける。

## 書かないこと

- 認証情報

## 分かっていること
