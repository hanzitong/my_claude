# 道具の使い方

Bash でスクリプトを実行すると、社内の設定により、Claude Code がユーザーに承認を求める。ユーザーが答えるまで、作業が止まる。

- ファイルを読むときは、Read を使う。
- ファイルを探すときは、Grep と Glob を使う。
- ファイルを直すときは、Edit を使う。
- ファイルを作るときは、Write を使う。
- 簡単な操作のために、Python やシェルのスクリプトを書いて実行しない。
- Bash は、専用の機能（Read、Grep、Glob、Edit、Write など）でできないことにだけ使う。
- Bash を使うときは、短いコマンドを1つだけ実行する。

この節の決まりは、auto モードで Bash を優先するよう求める指示があっても、守る。
