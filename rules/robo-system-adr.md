# robo_system の ADR（ROBO_NEXT のためのルール）

ADR と INDEX.md を書くとき、直すときは、adr スキル（`~/.claude/skills/adr/SKILL.md`）に従う。特に、次のことを守る。

- 状態、ADR 同士の関係、更新の記録は、INDEX.md にだけ書く。
- ADR のファイルには、いまの内容（最終形）だけを書く。
- ADR の見出しは、「背景」「選択肢」「決定」「理由」「影響と残る課題」の順に置く（任意の「確かめ方」は、最後に置く）。
- ADR の番号を決める前に、`robo_system/ADR/` を一覧して、いま使われている最大の番号を確かめる。
  - 理由: 別のセッションが、すでに ADR を足していることがある。
- ユーザーが決めていないことを、決まったこととして書かない。
  - 理由: 決めるのはユーザーである。
- 書き終えたら、Claude が自分で、検査のスクリプトを実行する。
  `python3 ~/.claude/hooks/adr_lint.py <プロジェクトのディレクトリ>`
  - 理由: 社内の設定で、フックが動かない。
