# Python の、中身が1行だけの関数（すべてのプロジェクトのためのルール）

- 中身が1行だけの関数は、作らない。その1行を、呼び出し側に直接書く。意味を伝えたいときは、呼び出し側にコメントを添える。
  - 理由: 2026-11-02 に、ユーザーが「1行だけの関数は今後禁止します」と指示した。その前に、`_create_seat_vlm`、`_create_care_vlm`、`_select_function`、`_greet_worker`（vlm_process.py）を、同じ理由で呼び出し側に直接書く形にしていた。
- 「1行」は、docstring とコメントを除いた関数の中身が、文1つだけであることを指す。この定義は Claude の解釈であり、ユーザーには確かめていない。
- 例外: 言語やフレームワークの都合で、関数として定義しなければならないものは、1行でもよい。基底クラスのメソッドの override、FastAPI の URL に対応する関数、スレッドの target、コールバックがこれに当たる。この例外は Claude の解釈であり、ユーザーには確かめていない。
- 例外: ログを出す関数（`_log_message` など）のように、汎用性が高く、多くの場所から使う関数は、1行でもよい。
  - 理由: 2026-11-02 に、ユーザーが「log などの汎用性が高いものに関しても例外です」と指示した。
- プロジェクトのルールが、ほかの例外を決めていることがある。そのときは、プロジェクトのルールにも従う。
- 既存のコードにある1行だけの関数は、ユーザーに頼まれたときに直す。
