# C++ の、中身が1行だけの関数（すべてのプロジェクトのためのルール）

- 中身が1行だけの関数は、作らない。その1行を、呼び出し側に直接書く。意味を伝えたいときは、呼び出し側にコメントを添える。
  - 理由: 2026-11-02 に、ユーザーが「1行だけの関数は今後禁止します」と指示した。
- 「1行」は、コメントを除いた関数の中身が、文1つだけであることを指す。この定義は Claude の解釈であり、ユーザーには確かめていない。
- 例外: 言語やライブラリの都合で、関数として定義しなければならないものは、1行でもよい。仮想関数の override、コールバックとして渡す関数がこれに当たる。この例外は Claude の解釈であり、ユーザーには確かめていない。
- 例外: ログを出す関数のように、汎用性が高く、多くの場所から使う関数は、1行でもよい。
  - 理由: 2026-11-02 に、ユーザーが「log などの汎用性が高いものに関しても例外です」と指示した。
- getter と setter は、このルールの例外にしない。扱いは `~/.claude/rules/cpp-getters-setters.md` に従う（使っている時点で、見直しが要る）。
- 既存のコードにある1行だけの関数は、ユーザーに頼まれたときに直す。
